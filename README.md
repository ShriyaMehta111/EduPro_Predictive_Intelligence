# EduPro Predictive Intelligence

## Predictive Modeling for Course Demand and Revenue Forecasting

EduPro Predictive Intelligence is a data science and machine learning project developed to analyze historical course, instructor, user, and transaction data and generate predictive insights for course demand and revenue performance.

The project is designed to help an online learning platform move from historical reporting toward data-driven planning by using machine learning, feature engineering, statistical analysis, and an interactive Streamlit dashboard.

---

## Project Overview

For an online learning platform, understanding future course demand and revenue performance can support important business decisions such as:

* Course planning and launch decisions
* Pricing strategy
* Instructor allocation
* Category-level performance analysis
* Revenue planning
* Identification of important course and instructor characteristics

This project uses historical EduPro data to analyze these factors and develop a predictive analytics solution.

---

## Problem Statement

EduPro has historical information about courses, instructors, users, and transactions, but historical data alone does not provide direct visibility into future course demand and revenue performance.

The project addresses this problem by developing predictive models and analytical dashboards that can help estimate enrollment demand and analyze revenue patterns using available historical data.

---

## Project Objectives

The main objectives of the project are:

1. Analyze historical course and transaction data.
2. Aggregate transaction information at the course level.
3. Develop features related to course and instructor characteristics.
4. Predict course enrollment demand using machine learning.
5. Analyze course-level revenue performance.
6. Compare revenue performance across course categories.
7. Identify important features influencing enrollment predictions.
8. Develop an interactive Streamlit dashboard for visualization and analysis.
9. Provide data-driven insights to support course planning and business decisions.

## Model Used

### Random Forest Regression

Random Forest Regression was used for enrollment demand prediction.

The model was selected because it can capture nonlinear relationships between course characteristics, instructor characteristics, and enrollment demand.

The initial model configuration included:

* Number of estimators: 200
* Maximum depth: 5
* Random state: 42

Hyperparameter tuning was also performed using GridSearchCV to explore different combinations of:

* Number of estimators
* Maximum depth
* Minimum samples split
* Minimum samples leaf

---

## Model Evaluation

The project uses standard regression evaluation metrics:

### Mean Absolute Error (MAE)

Measures the average absolute difference between actual and predicted values.

### Root Mean Squared Error (RMSE)

Measures prediction error while giving greater weight to larger errors.

### R² Score

Measures how much of the variation in the target variable is explained by the model.

Cross-validation was also used to evaluate model consistency across different subsets of the data.

## Limitations

The project has several limitations.

The analysis is based on the available EduPro dataset and therefore may not generalize to other online learning platforms. The number of courses available for course-level modeling is relatively limited, which can affect the reliability and generalization of machine learning results.

A substantial proportion of transactions have zero monetary value, which should be considered when interpreting revenue-related results.

The model identifies patterns and relationships within historical data but cannot guarantee future course performance. Model performance may also change as new courses, users, instructors, and transactions are added.

Regular model evaluation and retraining would therefore be recommended for a production environment.
